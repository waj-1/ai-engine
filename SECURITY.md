# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the repository's **Security** tab and
choose **Report a vulnerability**. You will get a reply within five working
days, and we will keep you informed until the issue is resolved.

Please include what you found, how to reproduce it, and which version or commit
you tested.

## Scope

This policy covers the code in this repository. The engine stores model
provider keys and can be connected to your own tools and data, so reports about
authentication, key storage, tenant isolation, and the tool and MCP boundaries
are especially welcome.

## Supported versions

Security fixes are made on the latest release.

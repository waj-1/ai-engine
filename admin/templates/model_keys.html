How keys are stored and used
  • Keys are encrypted with this server's SECRET_KEY before they reach the database. Without SECRET_KEY nothing is stored; a key is never saved as plain text.
  • Keep SECRET_KEY safe and backed up: without it the stored keys cannot be read and must be entered again. To change it, set SECRET_KEY=new,old, restart, and save each key again; then drop the old value.
  • A saved key is used by this engine from the next message. Other engine instances sharing the database pick it up within a minute.
  • Test asks the provider for its model list with the key in use. It costs nothing and sends no message. For Azure OpenAI it needs AZURE_OPENAI_ENDPOINT or a model with an endpoint.
  • Every save and removal is recorded under Activity, without the key.

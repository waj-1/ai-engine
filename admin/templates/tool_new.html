How it works

{% call info() %} On every call, the agent runtime builds a Pydantic model from your JSON schema and a StructuredTool wired to your endpoint via httpx. The LLM sees the description + schema and decides when to call it.

Auth: if auth_env_var is set and the agent service has that env var, requests carry Authorization: Bearer <value>. Secrets never hit the database.

Errors: non-2xx responses come back to the LLM as HTTP 4xx error: ... so it can self-correct rather than crash the turn. {% endcall %}

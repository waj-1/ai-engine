# Glossary

The words you'll see in the portal, in plain language.

| Word | What it means |
|---|---|
| **Agent** | One AI assistant with one job, such as customer support. See [Your agents](../02-agents/01-your-agents.md). |
| **Sub-agent** | An agent that another agent can hand part of a conversation to, such as a billing specialist. See [Sub-agents](../02-agents/04-sub-agents.md). |
| **Category** | A group you make to keep agents tidy, such as Support or Sales. It only organises the list; it doesn't change what an agent does. See [Group your agents into categories](../02-agents/09-categories.md). |
| **Template** | A ready-made starting point for a new agent. See [Create a new agent](../02-agents/07-new-agent.md). |
| **Instructions** | What the agent is told before every conversation: who it is, how it speaks, what it must and mustn't do. See [Change what your agent says](../02-agents/02-instructions.md). |
| **Toolset** | A group of related actions from one connected system. See [Tools and knowledge](../02-agents/03-tools-and-knowledge.md). |
| **Action** | One thing an agent can do in another system, such as "check outage" or "book a technician". Also called a tool. A **failed action** is one that didn't work. |
| **Knowledge base** | A collection of documents an agent can look answers up in, such as price lists or FAQs. See [Knowledge bases](../03-knowledge/01-knowledge-bases.md). |
| **Skill** | A reusable set of instructions for one task, which you can give to several agents. See [Skills](../03-knowledge/02-skills.md). |
| **Memory** | Facts an agent remembers about a person between conversations. See [Memory](../03-knowledge/03-memory.md). |
| **Channel** | A place customers reach your agents, such as a website chat, an app or a phone line. See [Channels](../04-connections/02-channels.md). |
| **Conversation** | One chat or one call between a customer and an agent. See [Review a conversation](../05-monitor/02-review-a-conversation.md). |
| **Needs attention** | A conversation where an action failed, an error happened, or a reply took more than a minute. |
| **Handed to a person** | The agent passed the customer to a member of your team. |
| **Test suite** | A set of practice conversations, each with what a good answer looks like. Each practice conversation is a **case**. See [Test suites](../06-testing/06-test-suites.md). |
| **Run** | One go of a test suite against an agent. See [Run a test](../06-testing/02-run-a-test.md). |
| **Score** | The share of cases that passed in a run, for example 85%. |
| **Target** | The score an agent must reach to count as good enough. |
| **Model comparison** | Running the same test suite on different AI models to see which one does best, and which one is recommended. See [Model comparison](../06-testing/04-model-comparison.md). |
| **Model** | The AI engine that writes the agent's replies. |
| **Version** | A saved copy of an agent's whole setup. You can compare versions and restore an earlier one. See [Versions](../02-agents/06-versions.md). |
| **Draft** | An agent that isn't serving customers yet, or a copy you're working on. New agents start as drafts. |
| **Live** | What customers get right now. An **Active** agent is live. |
| **Staging / Production** | On portals with a STAGING / PRODUCTION switch, two copies of every agent. You edit **Staging**; **Production** serves the version you last promoted. See [Make your changes live](../07-publishing/01-publish-changes.md). |
| **Promote** | Publish an agent's Staging setup to Production, in **Settings › Releases** or **More ▾ → Promote to Production…**. Each promote makes a new Production version, listed in **Promotion history**. |
| **Model key** | The secret a provider such as Google or OpenAI gives you so your agents can use its AI models. See [Add a model key](../08-team-and-settings/04-model-keys.md). |
| **Voice budget** | The number of voice-call minutes a business can use each day. See [Set the daily voice allowance](../08-team-and-settings/03-voice-budgets.md). |
| **API key** | A piece of text, starting with `wae_`, that lets a program use your agents without anyone signing in. See [Create and revoke API keys](../08-team-and-settings/04-api-keys.md). |
| **Admin** | A person who can sign in to the portal and change every agent and setting. See [Choose who can use the portal](../08-team-and-settings/01-team.md). |
